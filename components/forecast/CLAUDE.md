# components/forecast/
> L2 | 父级: ../../AGENTS.md

「时序预测」演示模式：历史 +（可选）事先已知的未来数据 → 未来 N 步的 P50 与 P10–P90 区间。全部由 `ForecastSpec`（`lib/forecast-scenarios.ts`）驱动：一页可以有几个预测对象，每个对象有自己的样例、时间列与目标列、上下文窗口、步长、已知输入列。

- `forecast-demo.tsx`: 「在线预测」标签页的主体，按预测对象重挂（切对象结果清空）。
  - 用样例：回测对象可选预测日（样例最后几天里有实测的），预测日之前的历史与当天的已知输入交给服务端读、上传 LimiX，结果与实测对账（误差、落在区间内的点数、扇形图上的实测线）；有 `gapDays` 的对象（实时电价第二天才公布）历史只到预测日前 gapDays + 1 天，图注写明；非回测对象预测样例结束之后。
  - 上传自己的表（限 4 MB）：目标列为空的尾部行就是要预测的点位，这些行里有值的其他列算已知输入。
  - 四张指标卡（对账误差或峰值上沿、预测峰值、平均区间宽度、耗时）、扇形图、前 24 个点明细。运行中按秒显示已用时间。
  - 调用本站 `GET /api/forecast`（样例名称、行数、可选预测日）与 `POST /api/forecast`（异步时序任务）。页头、预测对象切换与模拟提示在 `components/scenario`。

在线预测的设定要和离线评估一致（上下文天数、已知输入列、间隔天数），已知输入只放预测时真能拿到的列（按数据说明核对披露时点），页面「效果」的数字才对得上现场跑的结果。
