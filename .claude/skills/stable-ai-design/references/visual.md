# 传播物料（公众号封面、海报、方图）

> 由 `npm run build` 从 `design-system/visual/` 生成，不手改。设计系统 v1.0.0。

## 怎么出图

1. 先选模板和底色，把标题、说明等文字给用户确认。
2. 写一个 spec.json（可以是数组，一次出多张），在本 Skill 目录运行：

```
node visual/render.mjs spec.json --out 输出目录 --png
```

   输出 SVG；加 `--png` 时用本机 Chrome 导出 2 倍 PNG（找不到 Chrome 时设环境变量 `CHROME`）。有提醒（超宽、超行数、缺二维码、缺来源）时退出码为 2，改完再交付。字段示例见 `visual/example.json`，二维码字段写图片路径（相对 spec.json）。
3. 不要自己另写 SVG 或 HTML 版式。模板排不下时，先缩短文字；确实需要新版式时，按下面的规则排，并告诉用户这是模板之外的版式。

## 用途

- **适用**：公众号头条封面与 1:1 小图、活动海报、朋友圈和社群里的数据方图。渠道尺寸见「渠道规格」表。
- **先用模板**：每个渠道都有白底、渐变底和图形底三版。先在模板里换文字；模板排不下时，再按下面的规则自己排版，不要另起一套风格。

## 视觉元素

- **品牌渐变 `gradient-brand`**：橘红 → 品牌橙（62%）→ 橘黄，从左到右 90°。用作整张底色或大面积色块，不旋转，不改色标位置，也不叠其他颜色。
- **白底**：`white`。Logo、二维码和长段文字都放在白底上。
- **文字三色**：大标题用 `white`（只压在渐变上）或 `ink`（压在白底上）。渐变上的其余文字一律用 `ink`。白底上的说明文字用 `muted-foreground`，栏目小标题用 `primary-text`。
- **Logo**：白底上直接放横版组合 `logo-lockup-horizontal-hd.png`，小图用图形 `logo-mark-hd.png`，都是从设计师矢量源文件导出的透明底 PNG。放在渐变底上时，加白色圆角托板（`white`，圆角 `radius-md`，按画面尺寸等比放大），做法与深色主题相同。
- **标识图形**：Logo 里的双环图形放大后作大图形，从画面一角出血（超出画布的部分直接裁掉），用在「图形底」版。文件用 `logo-mark-xl.png`（高 2000px，从设计师源文件导出），只放大和裁切，不改色、不旋转、不拉伸、不描摹。画面里有大图形时，Logo 改用独立字标 `logo-wordmark-hd.png`，同一画面只出现一个双环。
- **点阵**（临时）：白色圆点，只铺在渐变右侧，从左到右渐显，不透明度 45%。点阵呼应「结构化数据」，是品牌方给出辅助图形之前的临时做法。
- **光影插图**（v0.39.0，可选）：需要配图时用光影风格：浅灰底，两道从左上斜照的白色窗光，设备画成白色实体加 `primary-text` 描边，圆柱有亮面暗面，物体统一向右下落影（投影色 `lit-shadow`），只有模型给出的结果用主色。光影插图里不铺点阵，也不和标识图形同画面。规则同 `design-system/README.md`「质感档：光影」。
- **字体与字重**：`font-display`（系统中文无衬线字体）。标题用 600，正文用 400 或 500，不用细体。

## 规则

- **白字只放在渐变左侧 60% 以内。** 白色在橘红上是 4.1:1，在品牌橙上是 3.1:1，在右端的橘黄上只有 2.2:1。所以白字要满足大字 3:1 的要求，只能放在左侧。模板已按这一宽度排版，超宽时会提示。
- 渐变上的白字至少 40px、字重 600，达到大字的标准；小于 40px 的文字用 `ink`。
- **Logo 只放在白底或白色托板上**，不放在橙色上，不单色化，不重新着色，四周留白不小于 Logo 高度的 1/4。公众号封面的渐变底版不放 Logo，由公众号名称标识。
- **标识图形只放白底**，不放在渐变或其他颜色上（橙色图形会和底色融在一起），也不和点阵同时出现。图形至少有一半留在画布内，能认出是双环；文字、数字和二维码不压在图形上，模板已把文字宽度收在图形之外。
- 每张图只讲一件事：一个标题，或者一个数。说明最多两行，信息行最多四行。
- 数值必须写来源；示例数据或脱敏数据要在图上注明。
- 不用蓝紫渐变、光效、表情符号、无关的 3D 素材和图库人物照。光影插图的窗光与投影不算光效；不加发光、光晕和光斑。不用金卡其，也不把 VI 的面色（橘黄、金桔）单独铺成底色。
- 语气和产品文案一致：短句，陈述事实，不用感叹号。中英文之间加空格，「LimiX」「Stable AI」按原样大小写。
- 按 2 倍尺寸导出 PNG，例如公众号封面导出 1800 × 766。需要再编辑时，另存一份 SVG。

## 已知情况

- 公司 Logo 已有设计师给的矢量源文件，模板用的是从它导出的 1232 × 360 PNG，海报按 2 倍导出也不会被放大。需要更大尺寸时，从源文件重新导出。
- 反白 Logo 只有候选稿（字标改白），还没确认。即使确认了，它也只适合品牌黑底：放在品牌渐变上，橙色图形会和底色融在一起。所以渐变底版继续用白色托板。
- 模板用的是系统中文字体，Windows 和 macOS 导出的字形会略有差异。需要字形完全一致时，在同一台机器上导出。
- 渠道尺寸按各平台当前的常用规格设定。平台改版后，以后台预览为准。

## 待品牌确认

1. **辅助图形**：VI 手册目前只接入了标准色一页。现在有两种临时做法：渐变上的点阵，和「图形底」里放大出血的标识图形。需要品牌方确认标识图形能否这样用、出血比例有没有限制；品牌方另有辅助图形时，替换这两种临时做法。
2. **标题字体**：是否指定一款可商用的中文标题字体。目前用的是系统字体。
3. **图片风格**：配图用实拍、产品截图、数据图形还是插画，需要一份范例集。2026-10-09 用户选定光影插图作为插画风格（见「视觉元素」），待品牌方确认后补范例集。
4. **LimiX 蓝版物料**：LimiX 模型相关的物料是否改用标准蓝。目前只做了公司橙版。
5. **反白 Logo**：候选稿在 `assets/Logos/candidates/`，品牌黑底上是否可用、渐变底上图形要不要改成单色白，需要品牌方决定。
