# 评估与结果页

回答「这个模型比基线好多少、差在哪」：先选基线，指标卡给差值，对比表给全貌，分工况表找弱项，导出把结论带走。

## 用途

- 一次评估完成后的结果页；从评估详情的「概览」或列表的「查看结果」进入。
- 多个模型版本、多个基线在同一验证集上的横向对比。
- 评估进行中不进本页，停留在详情页看进度。

## 结构

1. **返回** + **页面标题区**：标题「评估结果 · 对象名」，Badge 标明数据切分（验证集 / 测试集）与样本数；说明写明对照对象、时间窗口与步长。右侧 `outline`「重新评估」、「更多」菜单（导出 CSV / JSON、分享、归档）、`default`「导出报告」。
2. **基线选择**：一行，Select 列出可对照的基线；切换后指标卡、对比表的差值列与分工况表同步重算。
3. **指标卡行**：4 张（MAPE、R²、RMSE、推理耗时），每张「标签 / 当前值 / 差值 Badge + 基线值与好坏判断」。
4. **模型对比表**（整行）：行为模型，当前模型标 `accent` Badge「当前」并作选中行，基线标 `outline` Badge「基线」；列为类型、各指标、较基线差值、训练与推理耗时。
5. **预测与实际图**（7 列）+ **分工况表**（5 列）。
6. **局部说明**：某工况或时段明显偏弱时用 `default` Alert 给建议，放在网格最后一行。

## 规则

- 基线是页面级状态；差值一律「当前 − 基线」，带正负号，MAPE 差值用「pt」（百分点），比值指标不带单位；好坏由文案（「更好 / 更差 / 持平」）表达，不用红绿。
- 指标名沿用行业缩写（MAPE、RMSE、R²），单位放表头与卡片值后，「越低越好」的指标在说明里标明。
- 对比表每列最优值加粗，不上色；当前模型行 `selected`；基线行不高亮。
- 图表：当前模型 `chart-1` 2px，实际值 `chart-2` 1.5px，基线预测 `chart-baseline` 虚线；最多再加两条对照（`chart-3`、`chart-4`）。
- 导出：`default` 主操作只有「导出报告」（PDF），其他格式进「更多」菜单；导出成功用 Toast 报文件名，失败用 `destructive` Toast。
- 所有示例数值在说明里标注「示例数据」；真实页面写明数据日期与切分方式。
- 不在本页修改配置；「重新评估」跳到表单页并预填当前配置。

## 状态

- **加载中**：指标卡数值位与表格用 Skeleton；基线 Select 禁用。
- **切换基线**：指标卡与表格差值列即时重算，无需整页刷新；切换期间不出现加载态。
- **部分指标缺失**（如规则模型无训练耗时）：显示「—」，不留空、不写 0。
- **弱项提示**：存在分工况 MAPE 高于阈值时插入 Alert；无弱项时不渲染该行。
- **导出中**：主操作禁用并改为「正在生成…」；完成后恢复并 Toast。

## 响应式

- ≥ lg：指标卡 4 × 3 列；对比表整行；图 7 + 分工况 5。
- md：指标卡 2 × 6 列；图与分工况表各占整行。
- < sm 600：全部整行；操作区独占一行，主操作靠右；基线 Select 占满一行；对比表横向滚动，模型列保持在最左。
