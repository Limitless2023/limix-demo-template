# 页面级状态

页面在没有数据、正在取数据、取不到数据或不允许看数据时的样子：五种状态各有固定的触发条件、位置与文案格式，任何页型都要交代齐。

## 用途

- 列表、详情、表单、总览、评估页在正常内容之外必须覆盖的状态；接手一个页面时先核对这五种。
- 组件级的加载与错误（按钮提交中、字段校验错误）看各组件页；这里只讲整页或整块内容区。

## 结构

状态替换的是**内容区正文**，顶栏、面包屑与页面标题保持原位，用户始终知道自己在哪：

| 状态 | 触发条件 | 承载组件 | 标题区主操作 |
| --- | --- | --- | --- |
| 空态 | 请求成功，集合为空，且用户从未创建过 | Empty，动作为主操作 | 隐藏（由 Empty 承担） |
| 首次加载 | 页面首次请求，尚无任何数据 | Skeleton 复刻最终布局 | Skeleton 占位 |
| 局部加载 | 已有数据，正在刷新或翻页 | 旧内容降不透明度 + Progress / 文案 | 保留，可用 |
| 错误 | 请求失败、超时、服务异常 | `destructive` Alert + 重试按钮 | 保留 |
| 无权限 | 401 / 403，或对象对当前角色不可见 | Empty（左对齐）+ 申请入口 | 隐藏 |

## 规则

- **空态文案**：标题「还没有 ×」（对象名），说明一句「创建后能得到什么」，动作为该页主操作（`default`）；筛选无结果的空态见列表页型，标题改为「没有符合条件的 ×」，动作 `outline`「清除筛选」。空态居中，上下留 `space-16`。
- **首次加载**：Skeleton 数量与位置对应真实布局（标题、筛选、表头 + 5 行），容器标 `aria-busy="true"` 与 `aria-label`；不用转圈图标，不用整页遮罩；超过 8 秒仍未返回转为错误态并说明超时。
- **局部加载**：旧内容保留、不透明度降至 60%、`pointer-events: none`；进度可知时用 Progress 并写百分比，不可知时只写「正在刷新…」；不清空表格。
- **错误文案**：标题写「无法 + 动作 + 对象」（「无法加载评估列表」），说明写「原因（含错误码）+ 预期恢复方式」；动作区 `outline`「重试」在前，`ghost` 次级出路在后；下方用 `muted-foreground` 附请求 ID 与时间，便于反馈。重试中按钮禁用并改为「正在重试…」。
- **无权限文案**：标题「没有查看权限」或「没有操作权限」；说明写明范围与申请方式（「仅对 × 项目成员开放。向负责人申请后刷新本页」）；动作 `outline`「申请权限」+ `ghost`「返回 ×」；不显示主操作，不暴露对象内容。
- 状态块的宽度不超过 `--layout-prose-max-width`，错误与无权限左对齐，空态居中。
- 错误与无权限都不用插画和表情符号；语气陈述事实，不道歉式重复。
- 状态切换不改变滚动位置；内容到达后用 `fade` 动效替换 Skeleton（`duration-base`）。

## 状态

本页型自身即状态集合。预览顶部的切换条只用于演示，真实页面由数据与权限决定进入哪种状态；「错误」态点击「重试」会演示恢复到「正常」。

## 响应式

- 各状态块随内容区收窄，不做单独断点。
- < sm 600：Skeleton 表格只保留前两列；错误与无权限的动作按钮换行排列；空态上下留白收为 `space-8`。
