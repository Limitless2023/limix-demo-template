# 监控大屏

品牌黑下的实时监控与展示屏：指标、产线拓扑、模型运行状态与告警同屏；只有这个页型允许用运行中描边、数据流向、强调光晕与玻璃面板四种大屏效果，而且每种都必须对应状态或数据。

## 用途

- 产线中控室、调度大厅、客户展厅的常亮屏，以及夜间值守：远距离扫一眼就能看出「现在是否正常、哪里在运行、哪里出了问题」。
- 只用品牌黑（`orange-dark` / `blue-dark`）。日常产品里的总览用「总览 / 仪表盘」页型，浅色界面不用本页型的任何效果。
- 不承载编辑与配置；点击任一卡片跳转到对应的详情页处理。

## 结构

1. **屏头**：左侧屏名与口径（产线、模型），右侧采集状态（StatusDot `active` + `pulse`）、实时时钟（`mono`）与「示例数据」标注。
2. **指标行**：4 个 Stat，各占 3 列；本屏最重要的一个指标加 `.sa-glow`。
3. **拓扑与运行行**：产线拓扑 8 列（内联 SVG，连线用 `StableAI.motion.flow` 表达流量）+ 模型运行 4 列（正在推理的一项加 `.sa-motion-sweep`）。
4. **趋势与告警行**：实测（`chart-2` 实线）vs LimiX 预测（`foreground` 虚线）折线 8 列 + 告警列表 4 列（AlarmMark + 告警文字 + 时间）。
5. **图像底图（可选）**：地图、产线视频或热力图铺满屏幕底层时，所有面板改用 `.sa-glass`。

## 规则

- 四种效果各有含义，只用在对应处：运行中描边 = 正在运行（推理、训练、采集），数据流向 = 真实流量与方向，强调光晕 = 本屏最重要的一个数，玻璃面板 = 面板叠在图像底上仍可读。
- 同屏只有一处特效强调：运行中描边、强调光晕各只出现一次；多个对象同时运行时，描边只给当前关注的一个，其余用 StatusDot `active`。
- 数据流向的点数与速度由流量换算的 `rate`（0–1）决定，流量为 0 时调用返回的停止函数；不在没有数据含义的连线上放流向点。
- 玻璃面板只在有图像底时用；纯色底上保持 `card` 实色。面板描边用 `border`，不另加发光或多层阴影。
- 颜色只用主题变量：`primary`、`glow`、`surface-glass`、`chart-*`，告警处用 `alarm-*`（P3 紫只画告警标记）；不引入紫、青等额外强调色，不用渐变文字。
- 不用极光 / 网格渐变背景、漂浮粒子、所有卡片发光、列表交错入场；这些在动效原则第 7 条中明确不采用。
- 趋势图的本方预测线不用品牌橙：LimiX 预测用前景色 `foreground` 虚线（2px），实测用 `chart-2` 实线（1.5px）；扇形预测图用 FanChart `tone: 'neutral'`。品牌橙在监控类页面（监控大屏、设备监控、告警中心）只用于：导航选中、焦点环、本方模型或任务「运行中」（运行中描边、StatusDot `active`）、主操作按钮与表格行内的文字操作；不用于趋势线、预测线、流向点、数值与装饰——橙色放进监控画面会被读成告警（2026-09-23 用户决定，2026-10 按案例验证补全清单）。流向点在容器上设 `--sa-flow-dot: var(--foreground)`。
- 告警用 AlarmMark（颜色 + 形状 + 编号）、Stat `alert` 状态与告警列表表达；未确认的标记闪烁，不让整屏闪烁；图上的告警点用对应优先级的 `alarm-*` 与形状。数值颜色不随好坏变红绿。
- LimiX 预警（预测性，Alert）≠ 报警（Alarm）：预警不闪烁、不用 `alarm-*`，用描边 + 图标 + 文案。
- 系统开启「减少动态效果」时：描边变为静态主色、不生成流向点（路径箭头表达方向），光晕与玻璃不受影响（本身静止）。

## 状态

- **采集中断**：屏头 StatusDot 改为 `error`「采集中断 · 最后更新 hh:mm」，所有流向点停止，数值保留最后一次读数并在 Stat 说明里写明时间。
- **模型运行结束**：移除该项的 `.sa-motion-sweep`，状态改为「n 分钟前完成」；没有运行中的对象时，全屏不出现描边。
- **新告警**：告警列表顶部插入，对应 Stat 进入 `alert` 状态；不弹 Toast、不闪屏。
- **加载中**：指标数值位与图表区用 Skeleton 占位，拓扑先画节点与连线、不生成流向点。

## 响应式

- ≥ lg（大屏的常规宽度）：指标 4 × 3 列；拓扑 8 + 运行 4；趋势 8 + 告警 4。
- md：指标 2 × 6 列；拓扑、运行、趋势、告警各占整行 12 列。
- < sm 600：全部整行，内边距收为 `space-4`；拓扑 SVG 随宽度缩放，但最小 640px：再窄就在卡片内横向滚动（SVG 的 viewBox 缩放会连字一起缩，11px 的标签在手机上会被压到约 5px）。大屏页型在手机上只作查看，不保证远距离可读。
