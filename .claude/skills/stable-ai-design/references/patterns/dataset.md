# 数据集详情

一个数据版本的全貌：摘要说清它有多少行列、质量如何、还有几个待处理问题；主体按列画像、数据预览、质量问题、版本分区，右侧属性栏给出版本号、来源文件与解析配置。是 LimiX「上传 → 治理 → 预测」链路上用户停留最久的一页。

## 用途

- 上传完成后的落地页、数据集列表点击对象名进入的详情页、治理完成后查看新版本。
- 用户要在这里判断「这份数据能不能直接用来预测」：看列类型对不对、缺失多不多、有没有泄漏风险，再决定治理或直接新建预测。
- 不用于预测结果浏览（用评估与结果页）、不用于多份数据集对比（用列表页批量「对比」进入对比页）。

## 结构

1. **顶栏与返回**：面包屑「工作台 / 数据集 / 对象名」；内容区第一行 `ghost` 小按钮「返回数据集列表」。
2. **头部摘要**：左侧标题行（`heading-md` 数据集名 + `outline` Badge 数据类型 + VersionChip 当前版本）与一行元信息（来源文件、上传时间与人、解析配置概要）；右侧操作区：`outline`「下载」、「更多」DropdownMenu、`default`「用此数据新建预测」。
3. **摘要条**：4 张 Stat 等宽——行数、列数（说明里按类型拆分）、数据质量（Stat 下方嵌 QualityBar）、待处理问题（有高风险时 `state: 'alert'`）。
4. **主体**：8 列 Tabs（`line`）+ 4 列属性栏。Tabs 固定四个分区，顺序不变：
   - **列画像**：ToggleGroup 按类型筛选（全部 / 数值 / 类别 / 时间 / 文本），下方 ColumnProfile 卡片网格；缺失率高的列排在前面。
   - **数据预览**：DataGrid，表头带 ColumnTypeBadge 与紧凑 ColumnProfile，底部写「预览前 N 行，共 M 行」。
   - **质量问题**：IssueItem 列表按严重度排序；列表下方一行汇总「已采纳 x 项」与 `outline`「按已采纳建议生成新版本」。
   - **版本**：EventList 自上而下列出版本来历（上传 → 治理 → 生成），每条 `meta` 写版本号；下方 `outline`「对比版本」。
5. **属性栏**：Card + DescriptionList（`horizontal`）：数据版本（VersionChip）、版本类型、来源文件、解析配置（编码、sheet、分隔符）、行 / 列、被引用任务（TaskStatus 显示最近一次）；底部说明被引用的版本不能删除。

## 规则

- 一页只有一个 `default` 主按钮「用此数据新建预测」；治理与对比都是 `outline`，放在各自的 Tabs 分区里。
- 数据版本号一律用 VersionChip 显示并可复制；标题旁显示当前版本，属性栏再显示一次完整版本号。
- 列类型只用 ColumnTypeBadge 表达；类型是推断值，悬停显示源文件存储类型；类型错误通过「质量问题」的建议修正，不在列画像里就地改。
- 缺失率 ≥ 20% 的列在列画像里用 `destructive` 文字提示；不给整列或整张卡片上色。
- 质量问题的「采纳 / 忽略」只改变本页的待提交方案，不立即改数据；生成新版本前汇总行写清采纳数量，无采纳时按钮禁用。
- 数据预览只加载前 200 行；完整数据走「下载」。缺失值显示「—」。
- 删除版本只在「更多」菜单末尾，标 `destructive`，经 Dialog 确认；被任务引用的版本（LimiX 返回 4108）在 Dialog 里说明原因，不提供删除按钮。
- 页面上所有数值标注「示例数据」；真实页面写明上传时间与版本号。

## 状态

- **加载中**：摘要条与属性栏用 Skeleton 占位；Tabs 标题先渲染，内容区域 Skeleton。
- **解析中**（刚上传）：头部标题旁用 TaskStatus `running`；摘要条换成 Steps（上传 → 解析 → 画像），列画像与预览分区显示 Skeleton；完成后整页刷新为正常态，不跳转。
- **治理任务运行中**：「质量问题」分区顶部插入 `default` Alert「正在生成新版本」并带 TaskStatus；生成按钮禁用；完成后 Toast「已生成新版本」并提供「查看新版本」链接按钮。
- **解析失败**：头部下插入 `destructive` Alert，写明原因（编码、分隔符、表结构）与「重新上传」入口；Tabs 不渲染。
- **无问题**：「质量问题」分区显示 Empty「未发现质量问题」，摘要条问题数为 0 且不设 `alert`。
- **版本已删除 / 无权限**：整个内容区换成「页面级状态」页型的对应块，保留返回按钮。

## 响应式

- ≥ lg：摘要条 4 × 3 列；主体 8 + 4，属性栏在滚动时粘在顶栏之下。
- md：摘要条 2 × 2；主体仍 8 + 4。
- sm：属性栏移到 Tabs 之下占整行，不再粘顶；列画像网格每行 1–2 张。
- < sm：操作区独占一行，主操作靠右；标题降为 `heading-sm`；VersionChip 换行到标题下方；Tabs 横向滚动；内边距 `space-4`。
