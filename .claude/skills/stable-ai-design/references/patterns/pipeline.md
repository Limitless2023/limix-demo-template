# 任务流程

把一次 LimiX 调用链画出来：数据接入 → 数据治理 → 预测任务 → 评估报告（及可选的扩展任务），看清每一步的状态、产出的版本流向哪里、卡在哪一步；选中步骤后在右侧看接口、输入输出与错误。

## 用途

- 预测任务详情：从任务列表进入，回答「这个预测用了哪些数据版本、现在跑到哪、结果和评估在哪」。
- 失败排查：哪一步失败、错误码与原因、上游版本是否正常。
- 数据版本血缘、Agent 工作流执行记录等「看过程」的页面沿用同一结构，只换节点。
- 节点可拖动调整位置、「一键整理」恢复自动排布；不用于编辑或搭建流程（连线、增删节点），需要时另立页型。

## 结构

1. **页面标题区**：任务名 + 整体状态（取预测任务的状态，TaskStatus）；说明行写任务 ID（mono）、模型规格、任务类型与目标列。右侧操作随状态变：排队 / 运行中给 `outline`「取消任务」，失败给「重新提交」，`default`「查看评估报告」在评估完成前禁用。
2. **画布**（Canvas，左侧占满）：节点按调用顺序自动分层，从左到右；输入数据（预测集、真值集）贴着用到它的步骤放。
3. **详情栏**（右侧 320px）：选中步骤的类型、标题、状态；失败时先放 `destructive` Alert（错误码 + 原因 + 下一步）；再用 DescriptionList 列接口、输入版本、产出字段、耗时（ID 与版本用 mono）；最后是这一步的操作（下载结果、查看报告、查看数据集）。未选中时给一句引导。

## 规则

- 节点按 LimiX API 的真实步骤画，一个接口调用一个节点：数据接入 `POST /v1/data/files`、治理 `POST /v1/governance/tasks/confirm`、预测 `POST /v1/inference/{classification|regression|timeseries}/tasks`、评估 `POST /v1/evaluation/{…}/reports`、扩展任务 `POST /v1/extensions/…/tasks`。只读查询（轮询、下载）不画成节点。
- 状态传接口原始值，由 TaskStatus 统一中文：预测成功是 `finished`，接入 / 治理 / 扩展成功是 `succeeded`，接入复用是 `reused`；API 不返回的由前端推断：还没轮到的步骤 `pending`，未开启的可选步骤 `skipped`。
- 连线标签写中文短语（训练集版本、预测集版本、结果版本、真值版本），对应的字段名（`train_data_version_id`、`result_version_id`…）写在详情栏，不上画布。
- 画布卡片只放两三行关键值（行 × 列、模型、MAPE / R²）；请求参数、错误信息、说明文字进详情栏。默认视图缩到 85% 以下时卡片自动只留标题与状态，放大才看细节。
- 选中步骤时高亮它的上下游、其余调淡；连线标签只在选中路径上和悬停时出现。
- 没有可靠进度时不画进度条，只写耗时；排队时写「前方约 N 个」（`queued_snapshot_ahead_count`，估计值），不写预计完成时间。
- 取消只对未到终态的预测任务（`created` / `queued` / `running`）显示；评估是同步接口，没有排队与取消。
- 本方运行中的连线用主色流动（动效库「数据流向」），同一画布通常只有一两条线在动；其余连线靠实线 / 虚线区分是否已流经。
- 所有示例数值标注「示例数据」；真实页面的版本号、耗时、指标来自接口返回。

## 状态

- **排队中**：预测节点虚线框 +「排队中 · 前方约 N 个」；下游评估「未开始」；标题区给「取消任务」。
- **运行中**：预测节点主色描边，上游到预测的连线主色流动；耗时每秒更新；评估「未开始」。
- **已完成**：预测节点显示结果版本（VersionChip「结果」），评估节点显示 MAPE / R²；「查看评估报告」可用；所有连线为实线。
- **失败 / 超时**：预测节点 `destructive` 描边，指向它的连线变红色虚线；详情栏默认选中失败步骤并在最上方放 Alert；标题区给「重新提交」；下游保持「未开始」。
- **评估不可评估**（`report_status=failed`，不是系统错误）：评估节点显示失败，详情栏说明 `not_evaluable_reason`，不影响预测结果的下载。

## 响应式

- ≥ 1100：画布与详情栏左右并排（详情栏 320px）。
- < 1100：详情栏移到画布下方，整宽。
- < sm 600：画布高度收为 420，拖动平移查看；标题区操作独占一行，主操作靠右；页面内边距收为 `space-4`。
