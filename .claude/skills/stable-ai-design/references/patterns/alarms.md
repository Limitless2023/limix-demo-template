# 告警中心

值班人员处理报警的地方：按优先级汇总，按区域、状态与优先级筛选，逐条或批量确认、搁置、复位，并留下处置记录；LimiX 预警单列在下方，不混入报警。

## 用途

- 中控室与值班长的告警工作台：回答「现在有多少告警、哪些还没确认、哪些被搁置了、我刚处理了什么」。
- 浅色与品牌黑都可用：告警色、运行态与数据质量在两套主题下各有取值并已过对比度检查；中控室常亮屏建议品牌黑。
- 单台设备的测点与趋势看「设备监控」；告警组态（限值、优先级、抑制逻辑）不在本页修改。

## 结构

1. **顶栏**：Breadcrumb（工作台 / 告警中心）+ 口径说明与「示例数据」。
2. **告警横幅**：AlarmBanner，整行，显示最需要处理的一条（仍激活的未确认优先，其次已恢复未确认，再按优先级与时间）。
3. **标题区**：标题 + 范围（厂区、当班起始时间）；右侧 `outline`「导出当班记录」。
4. **汇总行**：6 块：P1–P4 各一块（AlarmMark `showLabel` + 激活条数）、未确认、搁置 / 抑制。
5. **主体**：区域树 3 列（AssetTree，节点汇聚告警）+ 告警表 9 列。
   - 筛选条：ToggleGroup（激活、未确认、搁置 / 抑制、全部）+ Select 优先级 + 右侧 `outline`「确认全部未确认」。
   - 告警表：优先级 / 状态（AlarmState，带优先级标记）、告警（文字 + 设备名）、位号（`mono`）、发生时间（`mono`，右对齐）、行内操作（确认、搁置、复位，`ghost` `sm`）。
6. **下方**：LimiX 预警 8 列（Alert 列表，`activity` 图标）+ 处置记录 4 列（EventList）。
7. **搁置抽屉**：Sheet，选搁置时长（最长 8 小时）与原因，唯一的 `default` 按钮「搁置」在这里。

## 规则

- 排序固定：优先级高的在前，同优先级按时间倒序；不允许按字母或位号默认排序。
- 告警只用 AlarmMark / AlarmState 表达优先级与状态：颜色 + 形状 + 编号三重编码；只有「未确认」的标记闪烁，确认后常亮；已恢复未确认画空心；搁置、设计抑制、停用画灰色虚线并写剩余时间或原因。整行不上色、不闪。
- 确认只改变确认状态，不消除异常；「已恢复 · 未确认」的告警确认后变为「已恢复 · 已确认」（AlarmState `ack-rtn`），移出激活列表，只在「已恢复」筛选与处置记录里保留。闭锁告警需要「复位」，确认不能替代复位。
- 搁置必须选时长与原因，到时自动恢复，写入处置记录；搁置、抑制中的告警不进横幅、不计入 P1–P4 激活数，单独计数。
- 批量确认只作用于当前筛选结果，按钮文字写清范围（「确认全部未确认」）；不提供「全部清除」。
- LimiX 预警（Alert）≠ 报警（Alarm）：预测性预警单列一区，用 Alert 的描边 + `activity` 图标 + 文案，写对象、依据与建议；不闪烁、不用 `alarm-*`、不参与确认与搁置、不计入告警数。
- 品牌橙在监控类页面（监控大屏、设备监控、告警中心）只用于：导航选中、焦点环、本方模型或任务「运行中」（运行中描边、StatusDot `active`）、主操作按钮与表格行内的文字操作；不用于趋势线、预测线、流向点、数值与装饰——橙色放进监控画面会被读成告警（2026-09-23 用户决定，2026-10 按案例验证补全清单）。本页的主操作是搁置抽屉里的主按钮。告警色不用于按钮与装饰。
- 所有告警与预警文字写对象与现象（「加热炉 4 区炉温高高限」），不写「严重！」「请立即处理」这类口号；标注「示例数据」。

## 状态

- **无激活告警**：横幅显示「无激活告警」，汇总全为 0，告警表显示空状态文字「当前筛选下没有告警」，处置记录照常显示。
- **告警洪流**（短时大量告警）：汇总与横幅照常更新，表格只渲染前 200 条并提示「还有 n 条，缩小区域或优先级后查看」；不自动批量确认。
- **采集中断**：横幅右侧加 StatusDot `error`「告警服务中断 · 最后更新 hh:mm」，表格保留最后状态并置灰操作按钮。
- **操作失败**（确认或搁置未写回）：行内保留原状态，Toast `destructive` 写明原因与重试方式。

## 响应式

- ≥ lg：汇总 6 块一行；区域树 3 列 + 告警表 9 列；LimiX 预警 8 列 + 处置记录 4 列。
- md（< 1100）：汇总 3 × 2；区域树移到表格上方整行；LimiX 预警与处置记录各占整行。
- < sm 600：汇总 2 × 3，内边距收为 `space-4`；筛选条换行，批量确认按钮左对齐；告警表在自身容器内横向滚动，页面不横向溢出；搁置抽屉占满宽度。
