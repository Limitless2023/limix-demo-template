# 表单页

创建或编辑一个对象：字段按主题分组成卡片，组内单列或双列；提交区固定在底部，有未保存更改时离开需确认。

## 用途

- 新建评估、创建数据集、编辑模型配置、项目设置等需要填 5 个以上字段的页面。
- 少于 5 个字段的快捷创建用 Dialog 内嵌表单；一步一屏的引导流程用向导，不用本页型。
- 只读展示用详情页，不把表单禁用后当详情页。

## 结构

1. **返回**与**页面标题区**：同详情页；标题为动宾短语「新建评估」「编辑数据集」，说明写明提交后会发生什么。
2. **表单主体**：宽度不超过 `--layout-prose-max-width` 720px，靠左；每个分组一张 Card，标题 + 一句说明，标题下有分隔线。
3. **分组内字段**：默认单列；成对或同量纲的字段（开始 / 结束、目标列 / 时间列）用双列，双列里跨行的字段加 `full`（React 版给 Field 传 `className="min-[600px]:col-span-2"`）。
4. **固定底部提交区**：贴底、白底、上描边、与内容区同宽。左侧未保存状态说明，右侧 `outline`「取消」+ `default` 主操作。内容区底部留出提交区高度的内边距。

## 规则

- 分组顺序按填写顺序：先「是什么」（名称、说明），再「用什么数据」，最后「怎么算 / 输出什么」。每组 3–6 个字段，超过就拆组。
- 不自带标签的控件用 Field 包住（标签 + 控件 + 说明 / 错误）；必填项传 `required`，标签后自动加「*」并写 `aria-required`，在页面说明里写「必填项带星号」；不给可选项加「（可选）」。
- 单列宽度即表单宽度；双列各占一半，不做三列。数字、日期等短字段也不缩短，靠分组和双列控制视觉长度。
- 帮助文本（`help`）写格式、范围与单位；错误文本写怎么改，不写「格式错误」。同一位置切换，避免布局跳动。
- 校验时机：单字段在失焦时校验；已出错的字段在输入时即时复核；提交时校验全部，聚焦并滚动到第一个错误，用 `destructive` Toast 汇总数量。
- 枚举少于 6 个用 RadioGroup；多选用 Checkbox；开关型设置用 Switch；条目多、需搜索的用 Combobox；其余用 Select。
- 主操作文案是动宾短语（「开始评估」「保存配置」），提交中禁用并改为「正在提交…」，不弹全屏遮罩。
- 离开确认：返回、取消或关闭页面时若有未保存更改，用 Dialog「放弃未保存的更改？」，确认按钮 `destructive`「放弃」，取消按钮文案「继续编辑」。无更改时直接离开。
- 提交成功后 Toast 报结果并跳到对象详情或列表；失败时在表单顶部插入 `destructive` Alert，保留已填内容。

## 状态

- **初始**：底部状态「尚未修改」；编辑态表单填入现有值。
- **已修改**：状态前有主色圆点，文案「有未保存的更改」；离开触发确认。
- **校验失败**：错误字段红描边 + 错误文本；提交按钮保持可用，便于修正后再次提交。
- **提交中**：主操作禁用并改文案；取消按钮保持可用。
- **提交失败**：表单顶部 Alert 说明原因；字段值不清空。
- **加载中**（编辑态）：分组卡片内用 Skeleton 占字段位置，提交区禁用。

## 响应式

- ≥ md：表单 720px 靠左，双列有效，提交区一行。
- < sm 600：双列改单列；提交区状态说明独占一行，按钮在下一行且主操作靠右；内边距 `space-4`。
- 提交区始终固定在底部，任何宽度下不遮挡最后一个字段（内容区底部内边距 ≥ 提交区高度）。
