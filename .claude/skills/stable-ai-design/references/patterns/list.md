# 列表 / 数据页

一类对象的集合：筛选区在上、数据表居中、分页在下；勾选后表格上方出现批量操作条。

## 用途

- 评估任务、数据集、模型版本、告警记录等「找一个、比几个、批量处理」的页面。
- 每行是一个可进入详情的对象；对象名进入详情，常用操作在末列用文字按钮直接点。
- 少于 5 条且不会增长的集合不做列表页，直接放在所属对象的详情页里。

## 结构

1. **页面标题区**：标题 + 一句范围说明；右侧 `default` 主操作（通常是「新建 ×」），次操作 `outline`。
2. **筛选区**：一行网格。搜索框最宽（2 份），其余筛选控件等宽，末尾 `ghost`「重置」。状态、类型等有限枚举用 Select；数据集、负责人等条目多的用 Combobox；时间范围用预设 Select，自定义区间才用日期控件。
3. **批量操作条**：只在有勾选时出现在表格上方，`accent` 底：已选数量、导出、对比、删除、取消选择。
4. **数据表**（Table 组件）：第一列勾选框，第二列对象名（`link` 按钮进入详情），中间为属性列，数值列靠右，最后一列「操作」：文字按钮（Button `ghost` + `sm`），如「查看 · 复制配置 · 删除」。
5. **分页**：左侧范围说明「第 1–20 条，共 128 条」，右侧 Pagination。

## 规则

- 筛选即时生效，不设「查询」按钮；筛选后分页左侧的条目数标注「（已筛选）」，重置按钮清空全部条件。
- 表格上方不放「共 N 条 · 每页 20 条 · 数据更新于」这类计数行：条目数只在分页左侧出现一次，数据更新时间写进表格 `caption`。
- 数值列传 `numeric: true`：右对齐、等宽数字；单位写进表头「MAPE (%)」「样本数」，不写在每个单元格。缺失值用「—」，不留空。
- 千分位用 `toLocaleString('zh-CN')`；百分比保留一位小数；时间用 `YYYY-MM-DD HH:mm`。
- 状态用 Badge：完成 `outline`、进行中 `accent`、失败 `destructive`、排队 `secondary`；不用橙色实底 Badge 表示普通状态。
- 行内操作最多 3 个文字按钮，常用在前、删除在末；多于 3 个时第 3 个换成「更多」DropdownMenu，删除放菜单末尾并标 `destructive`。操作列标题写「操作」，不留空。
- 批量删除与行内删除都走 Dialog 二次确认，说明后果；成功后 Toast 报数量。
- 表格说明（数据口径、更新时间）放 `caption`，不放在标题里。
- 超过 20 行分页；默认每页 20，不做无限滚动。
- 选中行底 `accent`；表头 `surface`（与侧栏同色）；悬停行 `muted`；不用斑马纹。

## 状态

- **空集合**（从未创建）：整块表格区域换成 Empty，动作为主操作「新建 ×」，此时页面标题区不再重复主按钮。
- **筛选无结果**：Empty 标题「没有符合条件的 ×」，动作为 `outline`「清除筛选」。
- **加载中**：首次进入用 Skeleton 占表头与 5 行；换页与筛选时表格保留旧数据、降低不透明度并禁用分页。
- **部分失败**：某行指标缺失显示「—」并用 Tooltip 说明原因，不整页报错。
- **已选**：批量操作条出现；「对比」在少于 2 项时禁用。

## 响应式

- ≥ lg：筛选区五控件一行；表格全列。
- md：筛选区改为搜索框整行 + 三控件一行；表格横向滚动（Table 自带 `overflow-x`），勾选列与对象名列保持在最左。
- sm 及以下：筛选控件两列；批量操作条与分页各自换行；操作列仍在末列，通过横向滚动到达；页面内边距收为 `space-4`。
- 390px 宽度下页面本身不横向溢出，只有表格容器内部可滚动。
