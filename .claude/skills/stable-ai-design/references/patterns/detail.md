# 详情页

一个对象的全貌：头部摘要说清它是什么、状态如何、关键指标多少；主体用 Tabs 分区放内容，右侧属性栏放键值对与负责人。

## 用途

- 一次评估、一个数据集、一个模型版本、一条告警的查看页；从列表页点对象名进入。
- 内容分区超过 3 个、或有需要常驻可见的属性时用本页型；只有一屏内容的对象用 Dialog 之外的抽屉或直接放在列表行展开里。
- 编辑对象走表单页，不在详情页里做整页可编辑。

## 结构

1. **返回**：内容区第一行，`ghost` 小按钮 + `arrow-left` 图标，文案写明去处「返回评估列表」；不用浏览器后退代替。
2. **头部摘要**：左侧标题行（`heading-md` 标题 + 状态 Badge + 类型 Badge）与一行元信息（编号、数据集、模型、创建人与时间，用 `space-4` 分隔）；右侧操作区。
3. **指标条**：4 格等宽，每格「标签 / 数值 / 对照说明」，数值用 `mono`；只放决定性的 2–4 个指标，其余进 Tabs。
4. **主体**：8 列 Tabs（`line` 变体）+ 4 列属性栏。Tabs 第一个是「概览」；属性栏是 Card，键值对用 `dl`，底部一个 `outline` 小按钮「编辑属性」。属性栏在滚动时粘在顶栏之下。

## 规则

- 操作区从左到右：`outline` 次操作、「更多」DropdownMenu、`default` 主操作靠最右；主操作一页只有一个，是对这个对象最常做的下一步（导出报告、开始评估）。
- 删除、归档等不可逆或低频操作只放在「更多」菜单里，删除标 `destructive` 且经 Dialog 确认。
- 标题不重复面包屑：面包屑末项是对象名，标题也是对象名，但标题旁多状态与类型 Badge。
- 指标条数值带单位（「38.4 kN」），对照说明写基线值和差值，差值带正负号与单位（「−1.3 pt」）。
- Tabs 内每个分区独立加载；切换 Tabs 不改变头部与属性栏。
- 属性栏只放静态键值，不放操作按钮（编辑入口除外）；长文本可换行，不截断。
- 记录、日志类内容用「时间 / 事件」两列，时间用 `mono` 12px `muted-foreground`。

## 状态

- **加载中**：头部摘要与指标条先用 Skeleton 占位；Tabs 与属性栏在数据到达后再渲染，避免布局跳动。
- **进行中**：状态 Badge 为 `accent`，指标条显示「计算中」并配 Progress；主操作改为「取消评估」`outline`，不给 `destructive`。
- **失败**：头部下方插入 `destructive` Alert 说明原因与重试入口；已有的部分结果仍展示。
- **对象不存在 / 无权限**：整个内容区换成「页面级状态」页型的无权限块，保留返回按钮。

## 响应式

- ≥ lg：8 + 4 分栏，指标条 4 格一行。
- md：指标条 2 × 2；主体仍 8 + 4。
- sm：属性栏移到 Tabs 之下，占整行；属性栏不再粘顶。
- < sm：操作区独占一行，主操作靠右；标题降为 `heading-sm`；记录列表的时间与事件上下排列；内边距 `space-4`。
